# 📜 Smart Certificate & Evaluation Tracker

Sistem manajemen sertifikat pelatihan dan kuesioner evaluasi peserta secara otomatis. Peserta wajib mengisi evaluasi terlebih dahulu untuk dapat mengunduh sertifikat.

---

## ✨ Fitur

### Untuk Peserta
- 🔐 Login dengan email & kode event unik
- 📝 Formulir evaluasi interaktif (Rating 1-5 + Feedback)
- 📥 Download sertifikat otomatis (terkunci setelah evaluasi)

### Untuk Admin
- 🔑 Login admin yang aman
- 📊 Dashboard analitik (total peserta, rata-rata rating)
- ➕ Buat/Edit/Hapus event pelatihan
- 📤 Upload template sertifikat (JPG/PNG)
- 👥 Lihat daftar peserta & status evaluasi
